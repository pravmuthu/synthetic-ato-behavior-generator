# Changelog

## 3.2.0 — Research-scale expansion (current)
- Refactored V3.1 pilot into a scalable CSV generator, 2,500 account / 90-day reference configuration.
- Preserved four cross-application ATO objectives and three illustrative application profiles.
- Added recurring per-user history and preference-conditioned routine navigation.
- Added normal sensitive account actions, rare legitimate automated clients, shared agency device fingerprints, varied networks, location overlap, MFA and failed logins, and quiet/blocked/completed episode variants.
- Added independent attacker-stealth and benign-complexity parameters, configurable label masking, opaque identifiers, and enriched but controlled positive case counts.
- Added evaluator-only action timing, completed-harm tracking and separate observed-vs-true labels.
- Added streaming validation of consistency, joins, actor labels, permissions, chronology, familiarity and basic category overlap.
- Known limitations: templates remain synthetic and externally uncalibrated; static access roles; no mid-session hijacking.
